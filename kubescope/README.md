# KubeScope

A multi-cluster Kubernetes and OpenShift console. Native desktop application (Tauri), tiling pane
layout, Svelte and TypeScript interface.

**Start with [`brief/00-kepernyo-brief.md`](brief/00-kepernyo-brief.md).** It says what this round
asks for and in what order.

| | |
|---|---|
| [`brief/00-kepernyo-brief.md`](brief/00-kepernyo-brief.md) | the brief: three directions first, then one design |
| [`brief/01-kepesseg-scope.md`](brief/01-kepesseg-scope.md) | the capability map — the contract about what the product does |
| [`brief/02-hol-tartunk.md`](brief/02-hol-tartunk.md) | the behaviour model: tiling, the two pane families, the real data, the sizes |
| [`brief/03-kepernyolista.md`](brief/03-kepernyolista.md) | the same capabilities arranged **by pane** — which kinds exist and what goes in each |
| [`brief/04-fogantyuk-kijeloles.md`](brief/04-fogantyuk-kijeloles.md) | **this round**: the handles, the drag gestures, and the whole grammar of selection |
| `design/` | where the work goes |

There is deliberately **no previous design system and no screenshot of the current interface** in
here. One was built, and it came out badly; showing it would anchor the next attempt to it. What we
learned from it is written out in the brief instead, as pitfalls rather than as pictures.

The briefs are in Hungarian. The output — component names, CSS, comments — should be in English.

## The grammar in one place

**Three bands, two thresholds.** `804` (already decided — the width at which `⊞` stops splitting)
and `480`. Tight = 382. Mid = 480–803, holds 638 and 572. Wide = 804 and up.

**638 is the base state.** Every specimen in this round was drawn at 638 *first* and widened. That
order is the point: designing at 1600 and cutting produces a narrow body that is a list of absences.

1. **The server decides what falls out** wherever it has an opinion — the `01-Resource-List` rule,
   inherited by everything carrying server-ranked material.
2. **A peer falls out; a structure becomes another structure.** This is why four panes needed drawing
   and eight tables did not.
3. **Every body has one load-bearing pair** — what it is, and the verdict on it. As fixed as `⊞ ✕`.
4. **Peers stack, sequences compress.** Reorder the elements: if the meaning changes, it is a sequence.
5. **The number outlives the bar.** A bar without its absolute is a percentage without one.
6. **Nothing scrolls sideways.** Every wide structure has a named transform instead; no exceptions.
7. **A body that dropped something says so once**, in the control bar, in one wording.

## The answers to the brief's open questions

- **The verdict column (§5.2, first block):** neither the name nor the verdict falls out — the row
  becomes two lines and the *evidence between them* goes. Certificates, waste and kubeconfig inherit
  the reason-sentence shape the resource list already uses, so the round adds no new row geometry.
  A **computed** verdict outranks the server's priority: the API has no field for "renew now",
  "orphaned" or "shadowed".
- **RBAC:** the matrix transposes to an 8-glyph strip per resource; at 382 the eight verbs become two
  verdicts, R and W, with `◐` for partial. Verb order is fixed at every width, so the pane offers no
  column sorting.
- **Helm:** three columns at 638 — the reference cluster plus the two that diverge most, never the
  first three alphabetically. At 382, one cluster paged with `‹ ›` against a 62px reference column.
- **Assistant:** chips leave the sentence at 638 and become numbered sources at 382. No claim without
  its citation, at any width. Prose is capped at 64 characters even at 1600.
- **Terminal:** 100 cols at 958, **65 at 638**, 40 at 382. Eighty columns needs 782px, so of the five
  reachable widths only 958 and 1600 clear it — the everyday shell in this product is a 65-column
  shell and most `kubectl` tables will wrap. We refuse both cheats (font under 11px, reflowing the
  output ourselves) and print the number instead.

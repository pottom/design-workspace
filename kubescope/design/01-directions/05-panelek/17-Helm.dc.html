WHAT WE CAN AND CANNOT KNOW
The release Secret stores two things: the merged user values and the chart’s own defaults. So “chart default versus overridden” is exact — we compute it, we do not guess.
What the Secret does not record is which file or flag a user value arrived through. Where a values file is committed and reachable we match it and name it; where we cannot, the row says --set or an untracked file rather than inventing a filename.
Subchart provenance is exact — the key path says it, and the parent’s override of a subchart default is the single most common surprise in Helm.
